3.2.0: Vanilla draws every slot. MenuKit no longer has a slot pass of its own on container screens: a created slot's panel writes the slot's position into vanilla's Slot.x and Slot.y before vanilla's slot pass, and vanilla draws the item, count, hover, and ghost icon for created and vanilla slots alike. A mod that decorates slots through an extractSlot mixin now marks created slots too, with no MenuKit dependency. Frame composition order on container screens is declared in one class (ContainerScreenLayers): flow panels below the slot pass, overlay panels and the modal dim above it. Panels on recipe-book screens no longer render twice per frame. Removed: the recipe-book render mixin. Breaks: CreatedSlotResolver now returns the in-menu Slot; SlotRendering keeps only the frame helper.
3.1.0: Button and Toggle accept a secondary-click handler (onSecondaryClick) that receives a Click with the button and modifier state (right, middle, shift+right); clicks with no handler still fall through to vanilla. Both also take a per-frame tint supplier (tint) for consumer-driven state such as a pinned mode. No breaks.
3.0.0: the Java package is now com.trevlar.menukit (was com.trevorschoeny.menukit); update imports. MenuKit and MenuKit: Containers now share one repository and one set of docs at github.com/trevorschoeny/menukit. No class or method names changed.
